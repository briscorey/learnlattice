Reading Distance-Time Graphs

Speed equals gradient. Flat means stationary. Steep means fast.

Rule 1: Gradient = Speed

Speed = distance ÷ time = rise ÷ run

Steeper line = faster. Gentle slope = slower.

Rule 2: Flat = Stationary

A horizontal line means not moving. Distance stays the same.

Rule 3: Going down = Returning

Line going down means moving back towards the start.

Example

0-10 min: line from 0 to 2 km | 10-15 min: flat at 2 km | 15-25 min: line from 2 km to 0

Phase 1: 2÷10 = 0.2 km/min = 12 km/h
Phase 2: stationary
Phase 3: 2÷10 = 0.2 km/min (returning)
