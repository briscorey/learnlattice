What I Built

📚

Resource Library

{{ len $resources }} resources across Mathematics, Biology, Chemistry, Physics, Earth Science, Space Science, and Ecology. Every resource is aligned to the IB MYP framework with key concepts, global contexts, and criterion mapping.

🎮

Interactive Games

{{ len $games }} browser-based educational games built from scratch: Probability Simulator, Equation Balancer, Cell Explorer, Function Machine, Food Web Builder, Tectonic Puzzle, Prime Maze, Circuit Builder, Geometry Transformer, Reaction Rate Lab. No downloads, no accounts.

📋

Assessment Toolkit

Criterion rubric cards for B, C, and D — projectable and printable. A searchable report comment bank with ~80 criterion-referenced comments. {{ len $exemplars }} annotated student work exemplars at three achievement levels.

💡

Understanding Layer

3 interactive visual concept explainers (Density, Algebra, Particles). 3 worked examples with step-by-step reveal. 30-term visual vocabulary builder. {{ len $withHints }} investigations with progressive "I'm Stuck" hints.

🧭

Teacher Support

{{ len $withMoves }} resources with specific, actionable Teacher Moves — practical guidance on what to do in the classroom, not what to know. Classroom Mode for projecting investigations step by step. Dark mode. Print stylesheets.

🗺️

Concept Map

Interactive D3.js concept map with 262 nodes showing how every investigation connects across subjects, topics, and MYP criteria. Force-directed physics simulation.

How I Built It

Static Site Generator: Hugo (v0.142.0)
Hosting: Cloudflare Pages (auto-deploy on push)
Source Control: GitHub
Design System: Custom CSS with subject colour system, SVG illustrations, dark mode
Interactive Tools: Vanilla JavaScript, D3.js, HTML5 Canvas
Accessibility: WCAG AA targets, reduced motion support, keyboard navigation
Performance: No frameworks, minimal JS, lazy loading, preconnect hints
