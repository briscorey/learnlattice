## Overview

Students investigate systems of two equations using concrete balance puzzles, graphical intersection, and systematic trial before encountering algebraic methods.

## The Investigation

### Phase 1 — Balance Puzzles
Present visual balance problems with shapes:
- 2 circles + 1 triangle = 10
- 1 circle + 2 triangles = 11
- "What is each shape worth?"

Students use logical reasoning and trial-and-improvement.

### Phase 2 — Real-World Setup
Present cost scenarios:
- 3 notebooks + 2 pens = $13
- 1 notebook + 4 pens = $11

Students set up tables of possibilities for each equation, then find the overlap.

### Phase 3 — Graphical Approach
Plot both equations on the same axes. The intersection point is the solution.

### Phase 4 — What If There's No Solution?
Investigate parallel lines (e.g. y = 2x + 1 and y = 2x + 5). Why can't both be true at the same time?

## Criterion B Alignment

| Strand | Evidence |
|--------|----------|
| Select a method | Choose between trial, tables, or graphical approaches |
| Apply strategies | Systematically test values that satisfy both constraints |
| Describe patterns | Explain why the intersection represents the solution |
| Verify | Substitute the answer back into both original equations |

## EAL Scaffolds
- **Sentence frame**: "The value x = ___ and y = ___ works because when I substitute into both equations, I get..."
- **Visual**: Balance scale diagrams alongside algebraic notation
