## The Task

> A pattern starts: 4, 7, 10, 13, 16, ...
>
> **Part (i):** Describe the pattern you observe.
>
> **Part (ii):** Find a general rule (formula) that gives the $n$th term of this sequence.
>
> **Part (iii):** Use your rule to predict the 100th term. Verify your rule works for the terms you can check.
>
> **Part (iv):** Justify why your rule must work for ALL terms in this sequence, not just the ones you tested.

---

## Assessment Criteria

This task assesses **Criterion B: Investigating Patterns**.

| Strand | Descriptor |
|--------|-----------|
| B.i | Select and apply mathematical problem-solving techniques to discover complex patterns |
| B.ii | Describe patterns as general rules consistent with findings |
| B.iii | Prove, or verify and justify, general rules |

## Student Response A — Achievement Level 3-4

### What the student wrote:

> **(i)** The pattern goes up by 3 each time. 4, 7, 10, 13, 16.
>
> **(ii)** The rule is times 3 plus 1. So the 5th number is 3 × 5 + 1 = 16. That works.
>
> **(iii)** The 100th term is 3 × 100 + 1 = 301.
>
> **(iv)** I checked it and it works so the rule is right.

### Annotation: Why This Is Level 3-4

**What this student does well:**
- Correctly identifies the common difference (+3) — this is accurate observation
- Finds the correct formula ($3n + 1$) — this shows some problem-solving
- Correctly calculates the 100th term — applies the rule

**What's missing for higher levels:**

The description in (i) is correct but minimal. "Goes up by 3" describes one feature of the pattern. A stronger response would connect the +3 to the structure of the formula.

The justification in (iv) is the critical weakness: "I checked it and it works" is **verification, not justification**. The student tested the rule against known values (which is good) but does not explain *why* the rule works. They cannot distinguish between "it works for the cases I tested" and "it must work for all cases."

**Key phrase to listen for:** "I checked" tells you the student is at the verification level. They are not yet at the justification level.

## Student Response B — Achievement Level 5-6

### What the student wrote:

> **(i)** The sequence starts at 4 and increases by 3 each time. This means it is a linear sequence with a common difference of 3. The terms are: T₁ = 4, T₂ = 7, T₃ = 10, T₄ = 13, T₅ = 16.
>
> **(ii)** Since the common difference is 3, the rule involves 3n. But 3 × 1 = 3 and the first term is 4, so I need to add 1. The general rule is $T_n = 3n + 1$.
>
> Checking: $T_1 = 3(1) + 1 = 4$ ✓, $T_2 = 3(2) + 1 = 7$ ✓, $T_5 = 3(5) + 1 = 16$ ✓
>
> **(iii)** $T_{100} = 3(100) + 1 = 301$
>
> **(iv)** The rule works because each term is 3 more than the last. Since 3n goes up by 3 every time n increases by 1, and the +1 accounts for the starting value, the formula matches the pattern. I verified it for all five given terms and it was correct every time.

### Annotation: Why This Is Level 5-6

**What this student does well:**
- Description is structured and uses mathematical vocabulary ("linear sequence," "common difference")
- Derives the formula logically (not by guess-and-check), showing how the common difference leads to $3n$ and the +1 comes from adjusting the first term
- Verification is systematic (checks multiple terms, not just one)

**What's missing for higher levels:**

The justification in (iv) is **stronger but still incomplete**. The student explains *why the formula produces the right structure* ("+3 each time") — this is genuine reasoning, not just checking. However:

- "I verified it for all five given terms" is still leaning on specific cases
- The student does not explain why the *linear* structure of $3n + 1$ necessarily produces a constant difference of 3 for ALL values of $n$
- There is no algebraic proof (e.g., showing that $T_{n+1} - T_n = 3$ for all $n$)

**Key phrase to listen for:** "The rule works because..." followed by a structural explanation. This student is reasoning about *why*, but has not yet reached formal justification.

## Student Response C — Achievement Level 7-8

### What the student wrote:

> **(i)** This is an arithmetic sequence with first term $a = 4$ and common difference $d = 3$. Each term is generated by adding 3 to the previous term: $T_1 = 4$, $T_2 = 4 + 3 = 7$, $T_3 = 4 + 2(3) = 10$, and so on. The $n$th term involves adding 3 a total of $(n - 1)$ times to the first term.
>
> **(ii)** From the pattern above: $T_n = 4 + (n-1) \times 3 = 4 + 3n - 3 = 3n + 1$.
>
> Verification: $T_1 = 3(1) + 1 = 4$ ✓, $T_3 = 3(3) + 1 = 10$ ✓, $T_5 = 3(5) + 1 = 16$ ✓
>
> **(iii)** $T_{100} = 3(100) + 1 = 301$
>
> **(iv)** I can prove this rule works for all terms by showing that the difference between any two consecutive terms is always 3:
>
> $T_{n+1} - T_n = [3(n+1) + 1] - [3n + 1] = 3n + 3 + 1 - 3n - 1 = 3$
>
> Since $T_{n+1} - T_n = 3$ for ALL values of $n$, the sequence always increases by 3. Combined with $T_1 = 3(1) + 1 = 4$ (which matches the given first term), this proves that $T_n = 3n + 1$ generates the entire sequence.
>
> This is not just true for the five terms we were given — it is algebraically true for every natural number $n$.

### Annotation: Why This Is Level 7-8

**What makes this exceptional:**

**(i) The description is structural, not just observational.** The student doesn't just say "it goes up by 3" — they explain that the $n$th term involves adding 3 exactly $(n-1)$ times to the first term. This reveals understanding of *how* the sequence is built, not just what it looks like.

**(ii) The formula is derived, not guessed.** The student builds the formula from first principles: $T_n = a + (n-1)d$, then simplifies. This is the general method, applied to a specific case.

**(iv) The justification is algebraic proof, not verification.** This is the critical distinction. The student:
- States what they will prove ("the difference between any two consecutive terms is always 3")
- Shows it algebraically ($T_{n+1} - T_n = 3$ for all $n$)
- Anchors the proof at $T_1 = 4$
- Explicitly states that this proves the rule for ALL values of $n$, not just the tested cases

**The sentence that makes it Level 7:** *"This is not just true for the five terms we were given — it is algebraically true for every natural number $n$."* This shows the student understands the difference between testing and proving.

## Teaching Notes: Using This Exemplar

### Before the assessment:
Show students Response A and ask: "What would you add to make this better?" Let them critique before they see B. Then show B and ask the same question. Then show C. The progression from verification → reasoning → proof becomes visible.

### After the assessment:
Use the annotations to explain achievement levels. Students who received 3-4 can see exactly what "justification" looks like at 5-6 and 7-8. The path forward is concrete, not abstract.

### For moderation:
These exemplars provide a shared reference point for teachers marking the same task. "Is this student's justification closer to Response B or Response C?" is a clearer question than "What level is this?"

### EAL note:
The mathematical notation carries the meaning. Students who cannot write fluent paragraphs can still demonstrate Level 7 thinking through algebraic manipulation. Response C's proof works even without the English sentences — the algebra speaks.
