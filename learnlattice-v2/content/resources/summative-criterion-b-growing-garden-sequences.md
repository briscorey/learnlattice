## Student Task Sheet

**Subject:** Mathematics | **Criterion:** B (Investigating Patterns) | **Time:** 55 minutes

**Instructions:** Show all working. Diagrams, tables, and written explanations are all important. You will be assessed on how you investigate, not just whether you get the right answer.

### The Problem

A gardener builds a square garden bed and surrounds it with border tiles. Each week, she makes the garden bed one size larger.

**Week 1:** A 1x1 garden bed surrounded by border tiles.
**Week 2:** A 2x2 garden bed surrounded by border tiles.
**Week 3:** A 3x3 garden bed surrounded by border tiles.

The garden bed (shaded) grows, but only the border tiles (unshaded) are counted.

### Part A: Explore (Levels 1-4)

1. Draw the border tile patterns for Weeks 1, 2, 3, and 4.

2. Count the number of border tiles for each week and record your results in a table.

| Week (n) | Garden size | Border tiles (T) |
|----------|-------------|-------------------|
| 1 | 1 x 1 | |
| 2 | 2 x 2 | |
| 3 | 3 x 3 | |
| 4 | 4 x 4 | |
| 5 | 5 x 5 | |

3. Describe the pattern you notice in the number of border tiles. What happens each week?

### Part B: Generalise (Levels 3-6)

4. Find a general rule that connects the week number (n) to the number of border tiles (T). Write it as a formula.

5. Use your rule to predict how many border tiles the gardener needs in **Week 20**.

6. The gardener has exactly 200 border tiles. What is the largest garden she can build? Show your working.

### Part C: Justify (Levels 5-8)

7. Test your rule by checking it against at least two values from your table. Does it give the correct number of border tiles?

8. Explain **why** your rule works. Refer to the structure of the diagram. Where does each part of your formula appear in the picture?

9. A student suggests the rule T = 4(n + 1). Another student suggests T = 4n + 4. Are these rules the same? Prove or disprove this claim.


## Task-Specific Rubric

### Levels 1-2
The student draws some diagrams and counts border tiles. A table is started but may contain errors. The pattern is described vaguely (e.g. "it gets bigger") without reference to specific numbers.

### Levels 3-4
The student correctly counts border tiles for at least 4 weeks. The table is complete and accurate. The pattern is described with reference to the common difference ("it goes up by 4 each time"). An attempt at a general rule is made, though it may be incorrect or incomplete.

### Levels 5-6
The student identifies a correct general rule (e.g. T = 4n + 4). The rule is used to make predictions beyond the table. The student tests the rule against known values and confirms it works. The response to the "200 tiles" question shows algebraic manipulation.

### Levels 7-8
The student explains why the rule works by connecting each part of the formula to the physical structure of the border (e.g. "4n comes from the four sides each having n tiles, and +4 accounts for the four corners"). The equivalence of T = 4(n+1) and T = 4n + 4 is proven algebraically. The justification is mathematical, not just descriptive.


## Marking Guide

### Part A

**Q1** (2 marks): Diagrams for Weeks 1-4 clearly showing the growing garden bed and the border tiles. Accept any clear visual. (1 mark for at least 3 correct diagrams, 2 marks for all 4)

**Q2** (3 marks): Table values are 8, 12, 16, 20, 24. (1 mark for 3 correct, 2 marks for 4 correct, 3 marks for all 5)

**Q3** (2 marks): The number of border tiles increases by 4 each week (1 mark). Starting value is 8 (1 mark). Accept equivalent phrasing.

### Part B

**Q4** (3 marks): T = 4n + 4 or any equivalent form such as T = 4(n + 1) (2 marks for correct rule, 1 mark for an attempt that shows understanding of the linear structure even if the constant is wrong).

**Q5** (2 marks): T = 4(20) + 4 = 84 border tiles (1 mark for substitution, 1 mark for correct answer).

**Q6** (3 marks): 4n + 4 = 200, so 4n = 196, so n = 49. The largest garden is 49 x 49. (1 mark for setting up equation, 1 mark for solving, 1 mark for interpreting the answer in context).

### Part C

**Q7** (2 marks): Tests at least two values from the table and confirms the rule gives the correct output. (1 mark per correct verification)

**Q8** (3 marks): Explains where the "4n" comes from in the structure (the four sides of the border, each with n tiles) (1 mark). Explains where the "+4" comes from (the four corner tiles) (1 mark). The explanation connects the formula to the diagram, not just to the number pattern (1 mark).

**Q9** (2 marks): 4(n + 1) = 4n + 4 by the distributive property (1 mark). Therefore the two rules are the same (1 mark). Accept a numerical proof (e.g. showing both give the same answer for multiple values) for 1 mark, but award 2 marks only for algebraic proof.

**Total: 22 marks**
