## The Hook

Cut three strips from card:
- 3cm
- 4cm
- 10cm

Try to form a triangle. **You cannot.** The two short sides do not reach each other.

Now try: 3cm, 4cm, and 6cm. It works.

**What is the rule?** When can three lengths form a triangle, and when is it impossible?

---

## The Investigation

### Experiment
Test these combinations. Record which form triangles and which do not:

| Sides | Triangle? | Why? |
|---|---|---|
| 3, 4, 5 | | |
| 3, 4, 7 | | |
| 3, 4, 8 | | |
| 5, 5, 5 | | |
| 2, 3, 6 | | |
| 5, 5, 9 | | |
| 1, 1, 2 | | |
| 6, 7, 8 | | |

### Find the Rule

> **The Triangle Inequality:** The sum of any two sides must be **greater than** the third side.

$$a + b > c \quad \text{AND} \quad a + c > b \quad \text{AND} \quad b + c > a$$

Test your rule against every combination above. Does it work every time?

---

## Extension

If two sides are 5cm and 8cm, what are the possible lengths for the third side?

> It must be greater than 3cm (8-5) and less than 13cm (8+5). So any length from 3.01cm to 12.99cm works.

---

## Teaching Notes

This is concrete before abstract. Students physically manipulate strips and discover the rule through failure — the moment they cannot close the triangle is visceral and memorable. Only after discovering the rule do they formalise it as an inequality.
