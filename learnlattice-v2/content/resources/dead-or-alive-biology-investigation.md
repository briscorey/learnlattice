## The Hook

Before students arrive, place these cards on each table — no instructions, no context:

> A candle flame. A crystal of salt growing in a solution. A dormant seed that hasn't germinated in 50 years. A virus. A stopped heart that will restart with a defibrillator. A robot that moves, senses its environment, and responds. A mule (which cannot reproduce).

Ask: **"Sort these into two groups: alive and not alive."**

What you will get is productive chaos. Every group will struggle with at least three of these. The flame moves, grows, requires fuel, and produces waste — but nearly everyone says it isn't alive. The virus can reproduce inside a host cell — but does nothing on its own. The seed hasn't been metabolically active for decades — is it alive?

The disagreements are the lesson. The point is not that students don't know the answer. It's that the question is harder than it appears — and answering it rigorously requires building criteria.

---

## Why This Investigation Matters

"What is life?" is not a solved problem. It is one of biology's most actively contested definitional questions. Astrobiologists at NASA need operational criteria to design life-detection experiments for Mars rovers. Doctors need legal and ethical criteria to define death. Virologists debate whether viruses are "alive" with genuine disagreement among experts.

By starting with this question, students do two things simultaneously:
1. They build genuine understanding of the characteristics of living things (not just recite them)
2. They encounter science as a process of definitional refinement — where the categories we use are human constructs, not given facts

## Core Concepts

### The Seven Characteristics of Life (MRS GREN)

**Movement** — Living things move, either their whole body (animals, some protists) or internally (plants growing toward light, blood circulating). Note: movement alone isn't sufficient — so does a river.

**Respiration** — ALL living things release energy from nutrients through chemical processes. This is not the same as breathing. Anaerobic bacteria respire without oxygen. The chemical equation:
$$C_6H_{12}O_6 + 6O_2 \rightarrow 6CO_2 + 6H_2O + \text{energy (ATP)}$$
(aerobic respiration in full)

**Sensitivity** — Living things detect and respond to changes in their environment. A plant turning toward light. An immune system responding to infection. A single-celled organism fleeing a toxic chemical.

**Growth** — Increase in size or complexity, driven by internal processes. Crystals "grow" but by external addition of material, not internal biochemistry.

**Reproduction** — Production of offspring, either sexually or asexually. This is the only characteristic that some biologists consider non-essential (mules, infertile individuals, and sterile worker bees cannot reproduce — are they not alive?).

**Excretion** — Removal of metabolic *waste products*. Not simply getting rid of undigested food (that's egestion) — excretion is the removal of substances produced *as a result of chemical reactions inside the organism*.

**Nutrition** — Taking in and using substances for energy and growth. Autotrophs (like plants) make their own. Heterotrophs (like animals) consume others.

### Cell Theory

All known living things share one additional feature: they are made of cells. The three core statements of cell theory:

1. All living organisms are composed of one or more cells.
2. The cell is the basic unit of life.
3. All cells arise from pre-existing cells (omnis cellula e cellula).

> **This is why viruses are controversial:** A virus is not a cell. It has no membrane-bound structure, no ribosomes, no capacity for independent metabolism. It is a strand of genetic information wrapped in protein. It can only replicate inside a host cell. By cell theory, it is not alive. By characteristics of life (it reproduces, it responds to the cellular environment), it might be.

### Step-by-step: Applying the criteria

**Example — A candle flame:**

| Characteristic | Does flame show it? | Notes |
|---------------|-------------------|-------|
| Movement | ✓ | Flickers, moves |
| Respiration | Partial | Requires fuel + O₂, releases CO₂ + H₂O — chemically similar |
| Sensitivity | Partial | Responds to wind |
| Growth | ✓ | Grows as more fuel is added |
| Reproduction | ✗ | Cannot produce offspring flames independently |
| Excretion | Partial | Releases CO₂, but not metabolic waste |
| Nutrition | Partial | Consumes fuel |
| **Cell-based?** | ✗ | Not made of cells |

**Verdict:** The flame meets many *functional* criteria but fails on reproduction and cell theory. The exercise reveals that the criteria are independent — an entity can satisfy 5 of 7 and still be non-living.

> **Formative checkpoint:** Ask: "If we found a Martian organism that reproduced, grew, and responded to its environment but had no cells and used silicon instead of carbon — would you call it alive?" This surfaces whether students understand the criteria as functional definitions or as Earth-centric descriptions.

## Investigation Tasks

### Part A — The Sorting Challenge

Working in groups, apply MRS GREN and cell theory to each entity on your card set. For each:
1. Mark each characteristic ✓, ✗, or ? (uncertain)
2. Write a one-sentence justification for each mark
3. Give a final verdict: alive / not alive / uncertain
4. Record which characteristic caused the most disagreement in your group

| Entity | M | R | S | G | R | E | N | Cell-based | Verdict |
|--------|---|---|---|---|---|---|---|-----------|---------|
| Candle flame | | | | | | | | | |
| Dormant seed | | | | | | | | | |
| Virus | | | | | | | | | |
| Growing salt crystal | | | | | | | | | |
| Mule | | | | | | | | | |
| Stopped-then-restarted heart | | | | | | | | | |
| Autonomous robot | | | | | | | | | |

### Part B — Class Comparison

Pool your group's verdicts with three other groups. For each entity, record where groups agreed and disagreed.

**Discussion questions:**
1. Which entity produced the most disagreement across the class? Why?
2. Is a virus alive? Write three sentences — the strongest argument that it IS, then the strongest argument that it IS NOT, then your personal verdict.
3. A biologist friend says: "Reproduction is the only truly essential characteristic of life — everything else can be absent in edge cases." Do you agree? Give a counter-example if you disagree.

### Part C — The Criteria Design Task

You are a NASA astrobiologist. You are designing a life-detection instrument for a probe landing on Enceladus (a moon of Saturn with a liquid water ocean beneath its ice surface). You have room for equipment to test for exactly **three** characteristics of life.

1. Which three characteristics would you choose? Explain why each is more detectable or more diagnostic than the ones you left out.
2. What would a positive result look like for each of your three chosen tests?
3. What is the risk of a *false positive* (detecting something that isn't life) for each test?
4. If your probe detected all three characteristics in a sample, how confident would you be that Enceladus has life? Explain your reasoning.

### Part D — The Reflection Task (Criterion D)

> *In 2023, scientists announced that a protein structure called a "prion" could self-replicate and evolve without any DNA or RNA — purely through changes in its physical folding. Prions cause diseases including BSE ("mad cow disease") and variant CJD in humans.*

1. Apply MRS GREN to a prion. Which characteristics does it show?
2. Does a prion meet cell theory criteria?
3. Using only the criteria from this investigation, write a justified verdict on whether prions are alive.
4. If we discovered that prions could evolve over thousands of years and become more "effective" at replicating — would that change your verdict? Should it?

## Formative Assessment Checkpoints

**Checkpoint 1 — During the initial sort:**
Walk around and ask individual students: "You said fire isn't alive. But it moves, consumes fuel, produces waste, and grows. Walk me through which criteria it fails." — You're testing whether students are applying criteria or using intuition.

**Checkpoint 2 — Before Part C:**
Exit slip: "Name one organism that fails to show at least one characteristic of life, but is unambiguously alive." 
Expected answers: mules (no reproduction), dormant seeds (minimal active metabolism), deep-sea organisms with no apparent movement. Students who can answer this understand the criteria are descriptive, not definitive.

**Checkpoint 3 — End of investigation:**
"Has your definition of 'alive' become broader or narrower after this investigation? Write one sentence saying what you added or removed."

## Common Misconceptions

| What students often believe | What's accurate |
|-----------------------------|----------------|
| "Living things breathe" | Respiration (cellular energy release) is universal; breathing (gas exchange via lungs) is one method in one clade of animals |
| "Things are either completely alive or completely dead — there's a clear line" | Many entities (viruses, prions, dormant seeds, spores) exist in a genuinely ambiguous zone that biologists actively debate |
| "Viruses are alive because they reproduce" | Viruses can only replicate by hijacking a host cell's machinery. Many biologists classify them as "non-living biological entities" |
| "Dead means stopped working" | A stopped heart can be restarted; a patient under anaesthesia has suppressed many life functions; a tardigrade in cryptobiosis shows no metabolic activity but is unambiguously alive |
| "MRS GREN is the definition of life" | MRS GREN is a useful mnemonic for common characteristics — it is not a universally agreed definition, and it fails for many edge cases |

## Teaching Notes

**On the hook:** The card sort is most powerful when done silently at first — no group discussion — so individual students commit to their initial intuitions before the social pressure of group consensus changes them. After 3 minutes of individual sorting, open to group discussion. The disagreements that emerge are more revealing than any correct answer.

**On viruses:** This is the richest edge case. The scientific community is genuinely divided. The International Committee on Taxonomy of Viruses (ICTV) does not classify viruses as living organisms. But virologists work with viruses as biological entities with evolutionary history, host specificity, and measurable characteristics. The "correct" answer depends on which definitional framework you apply — which is exactly the point.

**On Part C (NASA task):** The most common choices are: respiration (detectable via chemical signatures), cell-based structure (detectable via microscopy), and reproduction/DNA (detectable via PCR or genetic sequencing). Students who choose movement or sensitivity are thinking less carefully — these are harder to detect and less diagnostic. The false positive discussion is where the deepest thinking happens: chemical reactions can mimic respiration without life; crystalline structures can mimic cellular organisation.

**On the prion ending:** The prion revelation is genuinely recent (the Nobel Prize for prion research was awarded in 1997; the replication mechanism was still being established in 2023). It's appropriate to tell students that even the scientists who study this haven't fully settled the question of whether prions "evolve" in a biologically meaningful sense.

> **The bigger idea:** Biology is built on definitions. What counts as a cell. What counts as a species. What counts as alive. Every time these definitions are tested by an edge case, science either refines the definition or admits the boundary is blurry. This investigation introduces students to one of the most fundamental blurry boundaries in biology — and in doing so, shows them that science is not a collection of settled facts but an ongoing negotiation between evidence and the categories we use to organise it.
