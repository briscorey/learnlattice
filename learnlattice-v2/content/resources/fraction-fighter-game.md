A 5-stage fraction mastery game with visual bar models:

1. **See It**. Identify fractions from shaded bar models
2. **Same Value**. Find equivalent fractions (with visual proof)
3. **Compare**. Which fraction is bigger? Convert to compare
4. **Calculate**. Add and subtract fractions with different denominators
5. **Real World**. Pizza slices, recipes, batteries, and running distances
